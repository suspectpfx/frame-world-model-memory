# FRAME project page

Public research page for **FRAME: Consumer-Conditioned Memory Serving for World Models and Physical AI**.

- Live page: https://suspectpfx.github.io/frame-world-model-memory/
- Formal paper: https://suspectpfx.github.io/frame-world-model-memory/downloads/FRAME_Consumer_Conditioned_Memory_for_World_Models.pdf

The repository and GitHub Pages site are public. The page distinguishes executed measurements from proposed confirmatory studies; the learned-policy LIBERO controls validate integration but do not establish a calibrated FRAME Pareto gain.
