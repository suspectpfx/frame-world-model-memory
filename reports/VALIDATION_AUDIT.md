The current evidence supports a narrow systems thesis: memory records should be evaluated through the task loss and service constraints of their consumers, with fidelity, spatial granularity, physical layout, transform metadata, age, and temporal access represented separately. ## Claim classification

### Supported within the tested scope

1. **Consumer-conditioned memory utility.** Reconstruction quality and byte count alone do not specify whether a record is useful to a particular consumer. The formal contract correctly evaluates loss after representation, access adaptation, temporal access, and consumer execution.
2. **Addressability and information loss are different mechanisms.** A reversible permutation with a retained inverse is bijective. Pooling and downsampling are many-to-one transformations and can remove task-relevant degrees of freedom.
3. **Hidden layout degrades the tested spatial reader.** The reproduced hidden-permutation result is 1.0730 for the ratio-of-means estimand and 1.1208 for the mean-of-within-video-ratios estimand. The discrepancy comes from different aggregations, and both estimands are now labeled.
4. **Known inverse layout restores the tested utility.** Natural and inverse-recovered inputs match exactly, and the fixed-reader output is restored. The same equality reaches the learned policy input and executed action trajectory in the three sanity pairs.
5. **Serving paths have measurable implementation costs.** A–G arms charge writes, reads, metadata, and replication. The matched GPU comparison gives shared-canonical and permuted stores the same fused-adapter capability.

### Provisional

1. **Consumer-specific fidelity regimes.** Existing cached-video consumers show different responses, but the full confirmatory H1 design, practical-equivalence tolerances, and task-level embodied validation remain unrun.
2. **A conservative 2× spatial margin.** The current grid cannot establish this as a requirement. The legacy `p=0.019` value is hard-coded in the plotting script without a recoverable generating test, null hypothesis, tail, or seed. A clustered video bootstrap contradicts an exact-zero interpretation. The 2× observation can only motivate a predeclared practical-equivalence test.
3. **Layout preservation as a major optimization axis.** The measured operating points are deployment-specific. Larger payloads, additional transforms, parallel tenants, explicit cache states, and hardware counters are still needed.
4. **Novelty of the joint formulation.** The narrow combination of consumer task contracts, reversible layout metadata/adapters, lossy granularity, age, temporal channel, and measured service cost is differentiated from the cited work. A full literature review and completed H1/H3/H4 evaluation are still required before a strong priority claim.

### Unsupported or open

1. FRAME improves LIBERO task success, latency, energy, or a joint Pareto frontier.
2. A learned imagination channel maintains policy success under reduced observation access.
3. Latency changes the physical simulator state or task outcome under the current synchronous protocol.
4. The direction replicates on RoboTwin.
5. The public Wan-AI tokenizer is byte-identical or behaviorally equivalent to NVIDIA's access-restricted file.
6. Any broad claim that FRAME removes the need for a cost model.

## Novelty boundary

The mathematical invertibility of a permutation is established knowledge and is not a novelty claim. Tensor layout selection already optimizes operator layouts and conversion costs. Memory-augmented world models already study what historical observations improve persistent prediction. Controlled action-world-model studies already vary memory capacity, compression, readout, and recurrence. Latency-aware robotics benchmarks already provide dynamic evaluation semantics.

FRAME's defensible research question is narrower: how should a shared memory service represent, address, age, and serve one record to heterogeneous embodied consumers when task utility, reversible addressing, lossy spatial information, temporal access, and measured system cost all constrain the decision? The strongest publishable contribution will require evidence that this joint contract produces a frontier or a simplifying negative result that cannot be recovered by a fixed representation plus ordinary layout conversion.

## Advisor feedback closure

### Feedback 2 — preserve consumer layout versus inverse-permute on read

**Bounded closure on the tested deployment.** The implementation proves inverse correctness, reproduces fixed-reader utility recovery, measures serialized and resident metadata, compares canonical, hidden, materialized, fused-indirect, write-canonicalized, shared-adapter, and replicated layouts, and reports measured lifecycle cost over reuse, payload, rank, working-set, consumer-count, and CPU/GPU conditions. Reversible layout and lossy spatial aggregation are analyzed separately.

The result does not justify a universal layout policy. Cache-miss counters, DRAM transactions, broader transform families, large beyond-LLC records, parallel tenants, and predeclared practical-equivalence margins remain for deployment generalization.

### Feedback 1 — world model and Physical-AI benchmark

**Open.** The project now has a real learned action-conditioned model, closed-loop LIBERO execution, official task success, action latency, GPU-board energy, peak GPU memory, future-image predictions, and actual simulator trajectories. The intervention sanity run confirms that memory choices change executed actions.

Closure still requires a calibrated FRAME arm, a real learned imagination arm that is consumed by the next policy decision, paired population outcomes, latency-aware environment evolution, and a completed benchmark comparison. RoboTwin remains a replication phase after the LIBERO gate.
