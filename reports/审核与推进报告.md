# FRAME 专业审核与推进报告

本次结论：研究问题可以保留，但当前 project page 还不能支撑“真实世界模型驱动的闭环 Physical AI 系统”这一定位。导师 feedback 1 和 feedback 2 均未闭环。已完成的是源文件归档、重点存档结果复算、论点纠错、CPU 实现小试与可交接的实验方案。没有完成的实验不会在页面上写成结果。

## 一 核心论点

最强且稳妥的方向是：记忆质量由消费者实际任务效用定义，而表示精度 e、空间信息粒度 g、物理布局 l、转换元数据 m、记录年龄 Delta、访问通道 k 应分开建模。未知可逆映射造成 ADDRESSABILITY FAILURE；多对一池化造成 INFORMATION LOSS。后者不代表任务信息必然不足，前者也不代表必须用原始物理布局存储。

论文的新颖性应落在消费者任务约束下的表示、寻址、时效与服务联合决策，避免声称首次发现不同任务需要不同信息或首次给世界模型添加记忆。

## 二 所有 headline 的处置

`artifacts/claim_registry.csv` 保存原文陈述、出处、状态、统计字段和缺失说明；`CLAIMS.md` 提供主题级结论。注册表默认保守，旧文“confirmed”不自动变成新审计的 CONFIRMED。对存档数值的 CONFIRMED 仅表示明确限定的算术复算成立，不代表原始模型已经重新执行。

可以保留：消费者条件化的研究问题；存档空间读出对隐藏排列敏感；逆变换的恢复；特定粒度实验中 reader grid 附近误差变化。必须降级：强制 preserve layout、2x 硬要求、104 B 实测 metadata、微秒级可靠能量、无成本模型、零吞吐开销、LIBERO 闭环成功、596x 机器人节能。未解决：H1 跨 baseline 稳健性、H3 完整服务成本、H4 真实策略闭环收益。

旧稿中的 planner 负收益、verifier 退化、expiry 跨源变号、hedging 失败、最优阈值比较撤回和无法辨识的 crossing 全部保留，见 `FAILURES.md`。

## 三 关键差距及修正

1. **1.073 / 1.121 已查明是聚合方式差异。** 前者是 mean(loss)/mean(prior)，后者是 mean(loss/prior)。自然布局也必须相应从约 0.0520 改为约 0.0528，不能混搭。直接检查原 PNG 还发现图写 1.121、表写 1.073，图内自然布局仍写 0.052。旧稿 1.082 来自另一份 frame_ref3 结果；当前源代码与图片并非完整一致的版本链。
2. **104 B 不是实际元数据。** 源码仅算排列熵编码下界；实际 int64 inverse 为 1152 B。紧凑 uint8/uint16、共享映射、算法 seed 都应分别测真实序列化、驻留和解码成本。
3. **9.7 us 是一个 batch 的平均摊销值。** 不是 repeated-run median，也无单次 p95/p99。0.0017 mJ 则来自一次功率采样差乘时间，计量分辨率不足。
4. **p=0.019 是绘图硬编码。** 原始检验代码、tail 和 seed 不在归档。可重建的两组网格残差检验，单侧约 0.0201、双侧约 0.0421；它不是“高裕量组等于零”的检验，而且网格点共享视频。按视频成组 bootstrap，高裕量残差区间也高于零。是否可忽略必须先定义 equivalence margin。
5. **所谓额外误差是插值残差。** 不是相对 natural 的总误差。2x 指边长分辨率，二维 cell 数量是 4x。低 rank 对照不能支持统一 hard collapse。
6. **baseline 不统一。** 页面说所有实验都用同序列随机帧，layout 实际用常量输入的训练 prior；不能都叫 zero information。部分可视化用归一化 loss 排序，却用 raw loss 的 bootstrap 确认 winner，统计对象不一致。
7. **LIBERO 是扰动物体后固定动作重放。** 脚本没有 FRAME→模型→新动作→环境→新观察的因果链。imagine 的速度项代数抵消，并非学习动态。相同零偏移两次 replay 成功率还不一致，必须先解决 reset/controller/RNG。
8. **能量 frontier 拼接了不同实验。** 固定轨迹 success 与独立线性 latent rollout 的 cost 不能作为 E2E 点。energy/decision 除以成功率也不是 energy/successful episode。20 Hz 的 8 步为 400 ms，与 39.76 ms 感知、24 fps 文字混用。
9. **吞吐 best-of-five 有选择偏差。** 原 1.436 M 的五次中位数约 1.368 M。更严重的是“write”只加锁读取，索引冻结，miss 没有完整服务；不是动态缓存读写。
10. **容量与消费者控制仍不公平。** 某些 shard 配置的最小容量可超过声明总预算；共享 store 误差由 hit rate 和外部平均误差拼成。对象裁剪与 scene grid 改变信息支持，无法单独隔离 layout；每个 arm 重拟合 decoder 也不是固定 deployed consumer。
11. **“无成本项”推理不成立。** 即使 retrieve 在所有点都更便宜，当两通道都满足容忍阈值时仍需要成本做选择。两通道不等式也无法自动实现三通道决策。
12. **统计不显著不等于相同。** p=0.92 不能证明所有 task 的 success response 相同；共同噪声模型也不能证明 task 不存在差异。要保留任务层级，并区分误差规律与成功率饱和变换。
13. **比 natural 差，不等于已证明比 prior 差。** 隐藏排列相对 natural 的配对差异明确；但归一化 hidden loss 的区间包含 1。因此不能仅凭点估计超过 1 就宣称“比无记忆更差”，这需要另一个明确的检验。

完整逐文件说明见 `RESULTS_AUDIT.md`，新统计结果全部在 `artifacts/processed/` 与 `artifacts/statistics/`，不靠手填。

## 四 导师 feedback 到验收实验

Feedback 2：A canonical/direct；B 丢 metadata 负对照；C 读时 materialize；D 消费者间接 gather；E 写时 canonicalize；F shared canonical + adapters；G per-consumer replicas。先验证 inverse 和 consumer 输出，再测真实 metadata、写成本、读成本、F、消费者数、缓存、CPU/GPU、尾延迟与能量。最终给出 crossing、无 crossing 或在测量分辨率内无法区分；accuracy recovery 不能单独结题。

Feedback 1：先复现 Cosmos Policy 或满足条件的 pretrained action-conditioned 模型；三类 LIBERO task 各 40 paired initial conditions，10 arms，两种 timing semantics，共 2400 attempted episodes 的 pilot。输入必须由 memory wrapper 管理，重观察才能拿新视觉输入；明确 proprioception 合同。执行动作允许变化。通过 baseline、无泄漏、action intervention、稳定 timing 后再做完整 LIBERO，再做 5–10 项 RoboTwin。

## 五 数学形式

记录 r=(z,e,g,l,m,t_capture,t_write)，Delta=t_use−t_capture。

访问表示 x_access=Dec(e,g)(T(l→l_c)(z;m))；通道算子 Psi_k 根据真实执行 action history 得到 x_used。D_c=E[L_c(y_c(x_true(t_use)),f_c(x_used))]。

目标取 bytes、latency、energy 的 Pareto 最小集合，受 consumer distortion、capacity 和 deadline 约束。preferred layout 是性能偏好，不等于语义硬约束。字节预算无法满足合同必须显式报告 infeasible，并选择 eviction、别种表示或 reobserve。详细公式及成立条件见 `THEORY_REVISED.md`。

## 七 算力与时间风险

本机实测配置为 M2 / 8 GB unified memory / macOS。官方 Cosmos 基础 LIBERO 推理指标为 6.8 GB GPU VRAM，面向 Linux/NVIDIA，不能据此认定本机能运行，尤其不包括 planning 内存保证。已固化源码 commit；本地 baseline success、latency 和 VRAM 都是 NOT MEASURED。

规划估计：审计小时至天级；受控布局研究 1–3 天；模型接入 1–3 天；pilot 若每 episode 1–5 分钟则约 40–200 device-hours，必须用真实 baseline episode 时间替换假设。完整 LIBERO 与 RoboTwin 为后续天至周级投入，不自动启动。选择 alternative 必须满足模型能力与平台兼容，不能偷偷换回 constant velocity。

## 八 Stop go 条件

inverse 或 consumer 输出不匹配立即停止 profiling；metadata/copy 不完整不做成本结论；baseline 未复现、memory 不改变动作、ground truth 泄漏、各 arm 模型不一致、reset 不稳定、timing 未影响指定环境语义，都不扩大 pilot。无交点和负收益照常报告。最终统计锁定 task 层级、配对、主要效应、equivalence/noninferiority margin 和 Holm family；当前已有结果的重分析全部为 exploratory。
